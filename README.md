# Java Calculator Project

## Overview
This is a simple **Java Calculator** project. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division.

## Features
- **Addition**: Adds two numbers.
- **Subtraction**: Subtracts the second number from the first.
- **Multiplication**: Multiplies two numbers.
- **Division**: Divides the first number by the second.

## How to Use
1. Clone or download this repository to your local machine.
2. Open the `Calculator.java` file in any text editor or IDE (such as VS Code or IntelliJ).
3. Compile and run the program.
4. Follow the instructions to perform calculations.

## Technologies Used
- **Java** (JDK 8+)
